# 인테리어 견적 AI 어시스턴트

인테리어 견적서를 분석하고, 가견적을 제공하며, 견적 관련 질문에 답하는 AI 기반 플랫폼입니다.

## 모듈 구성

```
├── estimate/       # 가견적 엔진
├── chatbot/        # RAG 기반 챗봇 API
└── risk_detector/  # 견적서 위험 항목 탐지 API
```

### estimate — 가견적 엔진

네이버 카페(박목수 열린견적서)에서 실제 견적 데이터를 수집하고, Claude Vision으로 파싱한 뒤 ChromaDB에 적재합니다. 사용자의 공사 조건(평수, 지역, 공종 등)을 입력받아 유사 견적을 검색하고 가견적 범위를 반환합니다.

### chatbot — RAG 기반 챗봇 API

사용자 메시지와 대화 이력을 받아 의도를 분석하고 RAG 기반 응답을 반환합니다. 가격 비교, 누락 항목 확인, 하자 사례, 계약서 검토 등 인테리어 견적 관련 질문을 처리합니다.

### risk_detector — 견적서 위험 항목 탐지 API

업로드된 견적서와 공사 정보를 분석하여 누락·중복·불분명 항목을 탐지하고 위험도와 함께 반환합니다.
